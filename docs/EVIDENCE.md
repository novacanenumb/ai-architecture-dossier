# Evidence in this release

The 24 host-executed behavioral and statistical tests passed with no skips. They cover exact archive bytes, Unicode boundaries, scope isolation, correction history, race preconditions, deletion, deterministic ranking, pinned overflow, source-span recall, complete transport accounting and known statistical vectors.

The 17 fixed fixture configurations each reproduced exactly on a second execution. One deliberately undersized combined arm failed; it remains in the failure denominator. Seeded bootstrap intervals omit that failed pair from byte-efficiency inference and identify the omission. Repeated histories and related configurations do not form an independent sample of real user tasks.

For 64 milestones, 6,000-byte packet budgets and four workers, measured serialized input bytes were 37,075 full, 3,600 recent, 3,566 lexical retrieval, 3,892 sparse, and 4,440 combined. Required synthetic exact-span coverage was 100%, 0%, 100%, 100%, and 100% respectively. Byte reduction is not provider token reduction. The combined arm measures routing of exact facts, not the entire Hypervisor runtime or output from multiple models.

All 154 component endpoint comparisons against default models remain unavailable. All 122 full component acceptance requirements are either NOT_RUN or linked to partial reference evidence. No whole-component PASS is inferred from the narrow slice. Source-reported historical results are preserved as history and are not current measurements.

The native Hypervisor 2.1.0 source-proposal run reached REPORTED with persistence disabled, three Sol role proposals and valid GTFL collapse. Its declared validator was nonempty plus runtime schema/anchor gates. Parent integration corrected proposals independently. Seven source files match the retained artifact exactly; the catalogue builder has an explicit host modification allowing clean public builds. The host benchmark and publishing scripts are outside that source artifact.

Native telemetry reports 100% anchor first pass, critical path 915,514.816 ms, wall time 944,208.728 ms, and a 1.0220804 ratio using an estimated serial equivalent. Those intervals include orchestration and proposal waits. They are not hosted inference latency or a measured speedup against a separately executed default-model baseline. Tokens and cost remain null. Earlier timeout and output-budget failures remain recorded in the native receipt.

The complete source artifact, manifest, content-free ledger and performance record are under `experiments/native`. The final public release was checked for syntax, source hashes, catalogue counts, finite credential patterns, deterministic static rebuild and reconstruction without original source documents or the supplied runtime. These checks do not establish a comprehensive security audit, general semantic validation, publisher authenticity or live model quality.

Git initialization, commits, remote configuration and pushes use the user's task-scoped HYPERVISOR_BYPASS_APPROVED exception. They are not represented as Hypervisor Git-handler validated mutations.
