# Original Agent Database source evidence

The canonical source is `N:/Development/Production/Hypervisor Standalone/01_AGENT_DATABASE`, Python package `orpheus-agent-dashboard` 0.1.0 and logical component `hypervisor.agent_database`. It owns identities, scoped memory, agreements and worker supervision. Its documentation deprecates SOULS; these checks do not create or certify a separate C16 definition registry.

Nineteen inspected files are pinned in [the manifest](../experiments/agentdb/source-manifest.json): eight original Python modules, seven SQLite migrations, three original test files and package metadata. No original database, state directory, credential file or provider module is copied. The source remains unchanged and is excluded from the public release. The public additions are the runner, guard, synthetic probes and derived receipts.

`npm run test:agentdb` requires Node 26, the approved Hypervisor dependency, Python 3.12 and the exact original files. Override `AGENTDB_SOURCE_PATH`, `DOSSIER_PYTHON_PATH` and `DOSSIER_RUNTIME_PATH` for alternate locations. The current run used Python 3.12.0, pytest 9.1.1, pydantic 2.13.5, cryptography 50.0.1 and rfc8785 0.1.4. The runner pins these tested library versions, disables bytecode and third-party pytest autoload, and passes only named noncredential environment variables. Network, subprocess and writes outside the owned copy are denied by best-effort Python audit hooks; operating-system confinement is unavailable.

The [current receipt](../experiments/agentdb/test-receipt.json) contains 39 passing original tests, zero failures/skips/errors, and 10 passing new synthetic probes. Original suites cover resumable collection admission, scope, deletion, quotas, revision preconditions, selected-memory forks, policy attenuation, bounded negotiations, exact-byte agreements, challenges, approvals and revocation. New probes cover cache reuse, corrections, expiry, conflicting source assertions, frozen bootstrap artifacts and a single signed term change. The [acceptance map](../experiments/agentdb/coverage.json) retains partial status for C05, C17, C18 and C20 with explicit exclusions.

Two earlier guarded pytest setup attempts failed before collection. Pytest's default logging sink opened the operating-system null device outside the copy, which the write guard rejected. An explicit log file inside the copy resolved that setup fault. Both failed receipts and their source bytes remain under `history/attempt-1` and `history/attempt-2`. The first successful nine-probe run also remains under `history/attempt-3`; the current run adds the single-term signature probe. Failed setup attempts are not counted as successful tests or silently removed from experiment history.

The cold/warm comparison freezes [the protocol](../experiments/agentdb/cache-protocol.json) before execution. Thirty-two synthetic documents feed the same original `Memory.search` query. Eight counterbalanced pairs each run 16 cold queries and 16 warm queries: 16 arms, 256 measured queries and eight separately retained priming calls. The cold arm clears only the application retrieval cache before each query. The warm arm clears once, primes once and then measures cache reuse. Setup, clearing and priming are excluded from the per-query timing and retained separately. The operating-system/disk cache is not controlled.

Recorded cold mean query time is 0.8335578112 ms and warm mean is 0.0769312502 ms, a ratio of paired means of 10.8351. The paired difference is -0.7566265610 ms, with seeded 95 percent percentile-bootstrap interval [-0.7677729880, -0.7459683963] ms. All 16 arms and 256 measured queries succeeded; eight pairs are eligible, with zero exclusions and equal normalized result hashes. Durations vary; seeded arithmetic reproduces for the recorded vector. These observations describe this local synthetic retrieval fixture, without population or model-performance inference.

The original cache-hit path does not append internal latency samples. The new probe measures every cold and warm call externally and records that telemetry gap. Both arms retain hit counts and query records. Cached, failed and priming work remains distinguishable.

The single-term signature probe verifies two signatures on original approved agreement bytes, changes only `terms.retention_days`, and confirms both signatures reject the changed bytes. Private keys and signature values never enter the public receipt. Two session-only keys in one process do not establish independent custody or human consent. No real worker process or live model call ran. Billed tokens, cost, hosted latency, semantic qualification and full-model comparisons remain null or unavailable.
